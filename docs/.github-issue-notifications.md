# Add Notifications System to Dashboard

## Description
Implement a notifications system with a dropdown/popover notification center in the dashboard header, alongside the "Add Student" button. Users should be able to view and manage notifications without leaving the current page.

## Requirements

### UI Components
- [ ] Add notification bell icon button next to "Add Student" button in dashboard header
- [ ] Show notification count badge on bell icon when unread notifications exist
- [ ] Implement dropdown/popover that opens on click (not a separate page)
- [ ] Display notifications in a scrollable list within the popover
- [ ] Include "Mark all as read" action in notification popover
- [ ] Show notification metadata: timestamp, type, read/unread status
- [ ] Make notifications clickable to navigate to relevant content

### Backend Features
- [ ] Create Notification model in Prisma schema
  - id, userId, type, title, message, link, read status, createdAt
- [ ] Create API endpoints for notifications
  - GET /api/notifications (fetch user's notifications)
  - PATCH /api/notifications/:id/read (mark as read)
  - PATCH /api/notifications/mark-all-read
- [ ] Implement notification triggers for key events:
  - Student added
  - Lesson generated
  - Lesson shared
  - Learning plan completed
  - (extensible for future events)

### Email Integration
- [ ] Send email notifications for important events
- [ ] Include notification content and link to relevant dashboard section
- [ ] Allow users to manage email notification preferences
- [ ] Use existing email infrastructure (Resend)

### Technical Details
- Use Radix UI Popover or similar for notification dropdown
- Implement real-time notification count updates
- Add optimistic UI updates for read/unread actions
- Ensure mobile-responsive design
- Follow existing design system and color scheme

## User Flow
1. User sees notification bell icon with badge count (e.g., "3")
2. User clicks bell icon
3. Popover opens showing list of notifications
4. User can:
   - Click individual notification to mark as read and navigate
   - Click "Mark all as read" to clear all
   - Scroll through notification history
5. Notification count badge updates in real-time
6. User receives email for critical notifications
