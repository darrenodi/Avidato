# Avidato Tools Documentation

## Overview

Avidato Tools is a comprehensive library of AI-powered utilities designed to accelerate ESL lesson preparation and enhance student learning. With 40+ specialized tools, you can generate authentic materials tailored to your students' proficiency levels.

## How to Use Tools Effectively

### Step-by-Step Process

1. **Choose Your Tool** - Select from the category matching your teaching need
2. **Input Required Information** - Enter topic, text, or parameters
3. **Specify CEFR Level** - Match your student's proficiency level (A1-C2)
4. **Set Preferences** - Add any custom criteria or context
5. **Generate** - Click to create your material
6. **Review & Edit** - Always check quality and accuracy before using
7. **Use in Lesson** - Incorporate into your lesson activities

### Pro Tips

- **CEFR Level Matters** - Always match tool outputs to student proficiency
- **Combine Tools** - Use Vocabulary tools first, then create exercises with them
- **Check Quality** - AI-generated content should always be reviewed
- **Customize** - Add context information for better results
- **Build Lessons** - Use multiple tools to create comprehensive lessons
- **Save Time** - Prepare lessons in batches to maximize efficiency

## Common Tool Workflows

### Vocabulary Lesson Workflow
1. Start with **Essential Vocabulary on a Topic**
2. Use **Create Communicative Situations with Your Vocabulary**
3. Add **Word-Image Matching** for visual learners
4. Include **Create a List of Sentences with Your Vocabulary**
5. End with **Rephrase Using the Word Given**

### Reading Comprehension Workflow
1. Generate **Create a Text on Any Topic with Your Vocabulary**
2. Check reading level with **CEFR Level Checker**
3. Create questions using **Create ABCD Questions for a Text**
4. Add **Create Three Titles for a Text** for skimming
5. Use **Create Open Questions for a Text** for discussion

### Speaking Practice Workflow
1. Start with **Lead-in Activities for a Text**
2. Use **Find Discussion Questions** on topic
3. Add **Create a Dialogue on Any Topic**
4. Include **Create a List of Pros and Cons** for debate
5. Use **Find Interesting Facts** as discussion fuel

### Grammar Practice Workflow
1. Choose specific grammar point
2. Use **Grammar Rules** for explanation
3. Create exercises: **Fill in the Gap**, **Gaps with Brackets**, **Error Correction**
4. Add **Rewrite the Sentence** for production
5. End with **Create an Exercise with Matching Halves**

## Troubleshooting & Support

### Quality Issues
- **Low-quality output?** Provide more specific/detailed input
- **Wrong proficiency level?** Specify CEFR level more clearly
- **Irrelevant content?** Add context information

### Technical Issues
- **Generation failed?** Check internet connection and try again
- **Can't find a tool?** Use search feature or browse by category
- **Not enough content?** Run the tool again for variations
