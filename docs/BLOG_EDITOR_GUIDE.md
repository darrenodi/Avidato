# Blog Editor Guide

## Overview
The blog editor is now a **free-form text editor** with a comprehensive toolbar for applying styles to selected text. This follows the standard word processor pattern.

## How to Use

### Basic Workflow
1. **Type freely** - Write any content without restrictions
2. **Select text** - Highlight/select any text you want to format
3. **Apply styles** - Use the toolbar buttons to apply formatting to the selected text

## Available Styles & Tools

### Row 1: Heading Styles
- **Style Dropdown** - Change text to:
  - Normal text (paragraph)
  - Heading 1 (H1) - Large title
  - Heading 2 (H2) - Subtitle
  - Heading 3 (H3) - Section header
  - Heading 4 (H4)
  - Heading 5 (H5)
  - Heading 6 (H6)

### Row 2: Text Formatting
- **B (Bold)** - Make text bold (`Ctrl+B`)
- **I (Italic)** - Make text italic (`Ctrl+I`)
- **U (Underline)** - Underline text (`Ctrl+U`)
- **S (Strikethrough)** - Strike through text
- **</> (Inline Code)** - Mark text as code for technical terms

### Row 3: Text Alignment
- **⬅️ (Align Left)** - Left align text
- **⬇️ (Center)** - Center text
- **➡️ (Align Right)** - Right align text
- **≡ (Justify)** - Justify text

### Row 4: Lists & Blocks
- **• Bullet** - Create bullet point list
- **1. Ordered** - Create numbered list
- **" Quote** - Create blockquote (indented italic text)
- **{} Code Block** - Create code block with syntax highlighting

### Row 5: Insert & Undo/Redo
- **🔗 Link** - Add hyperlink to text
- **🖼️ Image** - Insert image by URL
- **↶ Undo** - Undo last action
- **↷ Redo** - Redo last action

## Visual Feedback
- **Active buttons are blue** - Shows which formatting is applied to the current selection
- **Disabled undo/redo buttons** - Become faded when no actions to undo/redo

## Features

✅ Free text input - type without restrictions  
✅ Select text and apply any style  
✅ Multiple heading levels (H1-H6)  
✅ Text formatting (bold, italic, underline, strikethrough, code)  
✅ Text alignment (left, center, right, justify)  
✅ Lists (bullet and numbered)  
✅ Blockquotes  
✅ Code blocks with syntax highlighting  
✅ Links and images  
✅ Full undo/redo support  
✅ HTML code view for advanced editing  
✅ Visual WYSIWYG editor

## Tips

1. **Apply multiple styles** - You can combine bold + italic + underline on the same text
2. **Code blocks vs inline code** - Use inline code for single terms, code blocks for multiple lines
3. **Switch between views** - Use the "Visual Editor" and "HTML Code" tabs to edit raw HTML if needed
4. **Undo powerful** - Make mistakes without worry, undo is always available
5. **Select wisely** - Only selected text gets formatting applied, so be precise with your selection

## Keyboard Shortcuts

- `Ctrl+B` (or `Cmd+B` on Mac) - Bold
- `Ctrl+I` (or `Cmd+I` on Mac) - Italic  
- `Ctrl+U` (or `Cmd+U` on Mac) - Underline
- `Ctrl+Z` - Undo
- `Ctrl+Shift+Z` - Redo
